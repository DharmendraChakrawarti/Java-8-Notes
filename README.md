## 🚀 How to Use These Notes

1. **Follow the order** – Topics are arranged from beginner to advanced.
2. **Run every example** – Copy the code snippets into your IDE or `jshell` and execute them.
3. **Modify and break** – Change variables, remove lines, see what errors come up, then fix them.
4. **Revise with the interview file** – Use `11_Interview_Questions.md` before any interview.
